## Summary

The speaker explains T3 Code, an open source app for working with AI coding agents. The team built it after they did not like the OpenAI Codex app or the Claude Code desktop app. The first versions were weaker than those apps. Over time, the team changed the sidebar, remote control, and subscription handling, and the project grew fast. The video says it had about 550,000 users and 140,000 weekly active users at the time of recording.

T3 Code is free to use, but you must bring your own AI subscriptions and your own compute. The team does not earn money from it. The speaker says it is expensive for the team to run.

## Main features

- **Many models and harnesses.** One app supports Codex, Claude, Cursor, Grok, OpenCode, Antigravity, and other tools. It also supports any tool that uses the ACP protocol. You can add several accounts for the same provider.
- **Parallel sub-agents.** One thread can start sub-agents that use different models. Threads can also talk to each other.
- **Remote control.** The command `npx t3 serve` starts a local web app over WebSocket. You can use it with Tailscale or with T3 Connect. T3 Connect is a tunnel service that links up to three devices for free.
- **Load balancing.** T3 Code can send new work to the machine with the most free capacity.
- **Inbox sidebar.** Each thread should be closed when it is done. You can settle, snooze, or archive it. Threads that have a merged PR settle by themselves. Working threads can hide in a separate section.
- **Background send.** Command plus Enter sends a prompt in the background, so you can start more work at once.
- **PR tools.** A built-in PR viewer shows PRs linked to a thread. You can merge PRs and see a merge readiness sort. The PR monitoring uses fewer GitHub API calls than agent-based polling.
- **Scheduled tasks and webhooks.** Threads can run on a schedule. They can also start from webhooks, and a webhook can hold events for up to 24 hours.
- **Usage tab.** The app shows token use by account and by machine.
- **Mobile app and simulators.** The mobile app can control remote machines. It can show iOS and Android simulators, including remote ones.
- **Other tools.** Drafts, stashes, theme support, HTML rendering in chat, file attachments that agents can open, snapshots with two Shift keys, a VS Code button that opens remote SSH, and project transfer between machines.
- **Triage command.** The command `npx t3 triage` gathers logs and context, then starts Claude Code or Codex to find the problem. The speaker says it solves over 80% of setup issues.

## Limits the speaker named

- You must bring your own compute and subscriptions.
- T3 Connect is limited to three free devices.
- Computer use is not built in yet. Some harnesses provide it.
- The nightly build changes often and can break for short times.
- The app can keep you up at night, and it can use tokens faster because you run more threads.

## Team and numbers

- Built by Julius, Maria, Theo (the speaker), and others.
- About 516 contributors.
- About 27,000 GitHub stars at the time of recording.
